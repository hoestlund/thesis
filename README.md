# Thesis

Repository for all the research for my final project as part of my degree "Computing and Information Systems". 


## Research Aims
i) See how sentiment can be used to predict broad market returns
ii) See if news data can be used in forecasting performance of indivuals sectors and companies
iii) See how the impacts of the spread and fight against corona impacted returns


## Data Sources
The data folder has the following overview
* companies
  * This is the tick data from all the companies that were analysed. These were gathered using the API from iexcloud
   
* indices
  * The html [source](https://finance.yahoo.com/quote/%5EGSPC/history) for the yahoo finance ^GSPC quote.
  * The date ranges were changed manually and then the open, close etc. prices were gathered
* kaggle
  * https://www.kaggle.com/notlucasp/financial-news-headlines
* reuters
  * The news headline data collected from webscraping scraping/reuters.ipynb
